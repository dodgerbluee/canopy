# UI24 — Android LAN photo upload compatibility

Status: ACCEPTED.

The photo queue computed a local SHA-256 digest before reserving an upload. Android browsers on the LAN HTTP origin do not expose `crypto.subtle`, so selecting an existing image threw before upload. Receipt uploads and reselected incomplete photo reservations shared that dependency.

All three paths now finalize with the checksum returned by the server's byte-upload receipt, matching the existing rounds flow. The shared transport validates a 64-character lowercase hexadecimal checksum before reporting success; malformed or missing checksum responses fail clearly without finalizing or attaching. The local digest helper and test-only SubtleCrypto polyfills were removed. No new crypto implementation, dependency, contract or backend changes. Original file bytes, metadata/date provenance, retries and upload recovery are preserved.
