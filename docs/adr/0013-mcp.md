# MCP domain adapter

Use the official Go SDK, finite named tool manifests, owner-issued scoped credentials and per-request authorization. Keep the browser cookie boundary separate.

Implementation refinement: reuse a private, bounded executable GraphQL operation bridge as the application facade. Each tool maps to a fixed allowlisted root and server-built selection; no tool accepts queries, root names or arbitrary selection sets. This invokes the existing typed resolvers/services/transactions without reproducing their orchestration and projections. Transport handlers cannot issue SQL. Internal actor context carries real agent/request identity; no synthetic login/session is created. Shared transaction hooks enforce grant validity, operation replay, proposal application and audit attribution. If a tool requires a capability absent from GraphQL, add a narrow typed service method.

The checked-in manifest is authoritative; scripts/gen_mcp.py generates the embedded runtime copy. Input schemas derive from the authoritative SDL with snake_case mapping; outputs pass a bounded public projection. Test schema generation, root coverage, permission filtering, union/date/currency behavior and absence of privileged roots. No provider-credential or arbitrary execution tools.

SDK v1.8.0 is pinned. SDK smoke tests are protocol-client evidence, not proof of a live Hermes/Grok Bot connection. Neither target client is currently installed; live account onboarding remains explicitly unverified until available. Hosted exposure is not enabled automatically.
