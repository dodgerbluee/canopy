# tests/ai-eval — T35 real-model evaluation and privacy/budget pilot

Deterministic case pack + opt-in live pilot for the three live AI paths
(text synthesis, vision comparison, receipt extraction). The Go driver
lives at `server/internal/insights/t35_eval_test.go` and shares this
pack.

## What runs where

| Suite | Make target | Network? | What it proves |
|---|---|---|---|
| `TestEvalRecorded` | `make test-ai-eval` | no | every recorded live output passes the REAL `ValidateResult` (100% schema + evidence-reference integrity) and its per-case honesty expectations |
| `TestEvalAdversarial` | `make test-ai-eval` | no | crafted hostile outputs (fabricated evidence ids, autonomous-action field, forged reconciliation, oversize) are REJECTED |
| `TestEvalLive` | `make test-ai-live` | yes (opt-in) | runs all 30 cases through the real Request→ProcessRun pipeline (incl. one bounded repair) against the configured providers and records sanitized results here |

The live pilot is probabilistic (real model, temperature 0.2): a case
that flakes is re-run, and the recorded results are what the
deterministic replay gate then pins forever. The provider template
(`canopy-eval-shim/v4`) states the validator's hard caps and phrasing
rules explicitly — the provider service is expected to know the
contract its output is judged against.

## The 30 cases

12 VISION pairs, 12 SYNTHESIS records, 6 RECEIPT images (`cases.json`).
Legality: every fixture is generated by `gen_fixtures.py` — no
third-party photos, no real user data, no licensed works. The
construction parameters ARE the label; synthetic pathology blotches
carry NO disease ground truth, so those cases gate abstention/hedging,
never diagnostic accuracy (see `docs/plan/05-verification.md`).

## Providers actually evaluated

- Model: `qwen3.8-flash-next-iq3_s` served by Strata
  (`http://192.168.69.130:8080`, OpenAI-compatible, self-hosted LAN).
- Vision: `VisionAnalyzer` speaks OpenAI chat-completions directly.
- Text + receipt structuring: the deployed text port speaks the
  Canopy-native `/v1/analyze` protocol, which Strata does not expose.
  `strata-shim.mjs` is the provider service for the pilot: it implements
  the Canopy wire contract on top of Strata's chat endpoint, with the
  prompt template pinned as `canopy-eval-shim/v4` (same role the e2e
  stub plays, but every answer comes from the real model). Run it:
  `docker run -d --name canopy-eval-shim -p 8099:8099 -e SHIM_PORT=8099
  -e STRATA_BASE=… -e STRATA_KEY=$STRATA_API_KEY -e STRATA_MODEL=…
  -v "$PWD/tests/ai-eval:/w:ro" node:24 node /w/strata-shim.mjs`
- OCR: local `canopy-media:r2` DockerSandbox (tesseract); receipt
  pixels never leave the machine.

## Privacy posture

- All evaluation inputs are synthetic (generated fixtures); no real
  user photos, receipts, or notes are sent anywhere.
- PlantNet identification is EXCLUDED from this live pilot: uploading
  real plant photos to a third party has not cleared its privacy gate,
  so IDENTIFICATION stays covered by the deterministic T31/T32 contract
  tests only. This exclusion is part of the pilot's documented outcome.
- API keys live in env only; `results/` records provider, model, prompt
  version, cost, snapshot and output — never keys.

## Price and budget accounting

- The self-hosted Strata endpoint reports no usage cost, so
  `costActualMicroUsd` is NULL in every recorded result. The budget
  machinery (per-workspace reservation, daily run caps, monthly
  ceiling) is exercised by the pipeline on every case; the price column
  of the pilot ledger is therefore "0 observed / unknown tariff", which
  is recorded honestly rather than invented.
- Sample caps: 30 cases, one bounded repair attempt per run, 256 KiB
  max response, 15 MiB max image, 150 s per-attempt timeout.

## Gates (from docs/plan/05-verification.md)

- 30 legally usable labeled cases — this pack.
- 100% schema + evidence-reference integrity — `TestEvalRecorded`.
- Zero fabricated evidence / autonomous-action outputs accepted —
  `TestEvalAdversarial` + validator.
- Abstention on every deliberately-underdetermined high-impact case —
  per-case `expect` (canker probe, pest uncertainty, unknown ID,
  incompatible pair, degraded image, sparse record).
- ≥90% reviewer-rated useful follow-up checks — `review-sheet.md`,
  filled by the human owner (required before acceptance).

## Findings logged during the pilot

- Receipt structuring honesty: the model initially claimed
  `needsReconciliation:false` on a subtotal+tax+total receipt because
  the printed arithmetic closes while the validator sums only `lines`.
  The shim template now states the closure rule exactly (tax must be
  its own line to claim closure) and the case converges first try.
- Pipeline gap flagged (NOT changed during evaluation, per packet):
  when `ReceiptOCR` internally rejects the structurer output
  (`ClassInvalidOutput`), the worker's bounded repair dispatches with
  `repairOf=nil` — a context-free retry that tends to repeat the same
  mistake. Worth a follow-up task to pass the rejected raw through.
- Provider template calibration (v1→v4), each step driven by a real
  rejection: v2 added the validator's banned causation phrasings
  (`caused/because of/due to/led to/resulted from/responsible for`)
  after a synthesis case asserted causation; v3 added the numeric caps
  (≤20 observations, ≤10 per other list, length bounds) after a case
  emitted >10 missingInformation entries; v4 states that "condition is
  unassessable" belongs in `missingInformation`, not as a HIGH
  hypothesis. All four rules are validator/reviewer policy the provider
  must know to comply — no output semantics were invented.
- Flakiness log (temperature 0.2): full runs recorded 29/30 (v2,
  t-seasonal-light causation phrasing), 29/30 (v3, t-schedule-drift
  epistemic statement), 30/30 clean (v4, `/tmp/t35_live_v4.txt`). The
  v3 failure was a driver heuristic gap: "condition … is unknown
  because no data are present" at HIGH is honesty about the record, not
  an overclaim about the plant, so the refusal regex now recognizes the
  "is/are unknown" class. Retry policy: re-run flaked cases; the
  replay gate pins whatever is recorded.
