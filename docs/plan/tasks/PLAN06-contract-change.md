# PLAN06 additive integration contract

Add `plantingEvents(from,to,first,after)` with a separate typed connection. Civil range is inclusive, at most 62 days, workspace-local today/timezone provided. Active parent plans only; each marker represents an explicitly scheduled action, with its current state and stable plan/action IDs. No inferred source/window event, plant ID or recorded completion is fabricated. Cursor binds workspace/range; rows sort by scheduled day and action ID.

Add notification reference kind PLANTING_ACTION. Optional action reminderOn opts into one in-app notification at 09:00 on that workspace civil day; a missed run can catch up for seven days while the action is still open. No email. One key per workspace/action/schedule revision/recipient, immutable history; rescheduling, cancellation, completion or deletion prevents any old pending delivery. A bounded River sweep selects eligible current rows, locks/revalidates parent state and action, then inserts the existing notification intent atomically. Future reminders are not prematerialized. Workspace timezone changes recompute unsent instants while civil dates stay unchanged. Legacy enum values are retained on migration down, matching existing care enum migration practice.
